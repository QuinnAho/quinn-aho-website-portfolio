What I'm building now

IntentGraph — a spec-driven IDE plugin. You work in a living graph of intent, constraints, decisions, and rationale; AI keeps the implementation in sync, both directions.

Code becomes a verifiable projection of intent: when you edit the graph, AI proposes a patch in a worktree shadow; when you edit code, the graph detects drift in under two seconds.

The bet is that AI-augmented codebases need persistent program theory the team can audit, not markdown docs that go stale. The architecture enforces faithfulness as a structural property — every agent action records concrete artifacts (tool calls, retrieved nodes, model version, verifier outcomes), and the monitor LLM is never trained against its own signal.

27 ADRs in. TypeScript-first, VS Code-first, with one MCP server consumed identically by Claude Code, Codex, and the extension itself.

Featured work

Five projects that carry the thesis.

  • ClaudeMap Google Maps for AI-augmented codebases.

    An open-source Claude Code plugin that builds a navigable concept-organized map of any repo. Code clusters by what it actually does, with health overlays showing what's working and what's broken. Slash commands drive the map: /explain walks Claude through any path, /show jumps to whatever you ask for.

    233★ on GitHub · 541 npm downloads · 160 in a single day on the v0.2.0 release · Distributed as @quinnaho/claudemap.

    Stack. JavaScript · MCP · Claude Code skills.

    GitHub npm Loom demo Live preview

  • Glint3D A 3D engine designed for humans and machines.

    Custom C++/OpenGL engine with two equal surfaces: an interactive UI for human scene editing, and a JSON Ops pipeline + headless CLI for AI and automation workflows. PBR materials, glTF/FBX/OBJ/PLY import, both rasterization and CPU ray-tracing paths. The dual-mode design isn't rhetoric — it's enforced by the data format (JSON Ops with a versioned schema) so both audiences operate on the same primitives.

    Includes an in-tree QEM mesh decimation algorithm, exposed standalone as QEM Studio with feature-aware preservation of boundaries, sharp edges, and high-curvature regions. QEM Studio's performance writeup documents a +91% slowdown from a "textbook" optimization, why it happened, and why it was reverted — the kind of result most projects don't publish.

    Stack. C++ · OpenGL · GLSL · CMake · Assimp · Eigen · Dear ImGui.

    GitHub QEM Studio

  • Blueprint Health Analyzer A static analyzer for Unreal Engine Blueprints.

    An Unreal Editor plugin and commandlet that audits Blueprint and asset health across a project. Three scan modes: full project, current selection, or any asset and everything that depends on it. Produces deterministic reports with stable signature hashing, so the same plugin powers both the editor dashboard and CI quality gates that fail builds on critical findings.

    Built under the immersalab label. Targets UE 5.6 / 5.7. The first commercial product I've shipped on a real engine.

    Stack. C++ · Unreal Engine 5.

    Demo video Docs site GitHub

  • PhasePal An AI desktop companion that lives on your screen.

    Real-time LLM chat with animated 3D characters, voice synthesis, and local/cloud provider routing. Founding Unity Engineer at Consistency AI (Oct 2025 – Jan 2026). I built the inference latency optimization across multiple LLM backends, the safety guardrails for real-time AI conversations, and the Unity character systems — cursor tracking, window perching, VRM model support, state machines.

    Shipped on Steam.

    Stack. Unity (C#) · VRM · multiple LLM backends · voice synthesis.

    Steam page

  • Milestone Local AI task management with structural guardrails.

    A local-first tool with an ai/ folder full of contracts, schemas, and per-task progress logs that AI agents must follow. Every agent reads its AI_*_CONTRACT.md and writes progress into structured NDJSON — so a task literally can't be marked complete without the right log entries. The guardrails (Machine Summary Blocks, schema-validated checklists, diff payloads) are the product.

    The thesis: AI productivity collapses without legibility surfaces, and the surfaces have to be enforced, not requested.

    Stack. TypeScript · React/Vite · Express · NDJSON.

About

I build tools for working with complex systems honestly. Sometimes the system is a codebase, sometimes a 3D scene, sometimes a training simulator. The throughline is that AI is making these systems faster to produce than humans can understand them, and I think the answer is better surfaces — graphs over file trees, intent over implementation, structural verification over hopeful rationales.

I've spent the last four years on the graphics and XR side of that problem. At Johns Hopkins APL, I deploy military training simulations in Unity for active defense programs and prototype next-generation immersive trainers in Unreal — one of those prototypes earned internal honors and helped secure five years of continued funding for its program. Before APL, I built VR visualization tools at Corvid Technologies, vehicle digital-twin tooling at GS Engineering, and the real-time MetaHuman animation pipeline for NextGenCoding's DJ Khaled launch.

The last 18 months I've been building on the AI-tools side too. ClaudeMap is the public one — 233★ on GitHub, real npm downloads, an open-source codebase visualization tool that started as a hackathon project. Blueprint Health Analyzer is the commercial one. IntentGraph is what I'm building now, and it's the most ambitious of the three.

I'm graduating from Wayne State University in May 2026 with a B.S. in Computer Science Engineering (3.86 in CS coursework, 3.2 cumulative). Looking for research engineer and early-stage builder roles in San Francisco where graphics, AI tooling, and human-AI collaboration meet.
